# Beyond Basik Income Tax

Static multi-page website for Beyond Basik Income Tax.

## Local preview

```powershell
py -m http.server 3000
```

Open `http://localhost:3000`.

## Pages

- `/` — Home
- `/services/` — Services
- `/how-it-works/` — How It Works
- `/why-us/` — Why Us
- `/reviews/` — Reviews
- `/contact/` — Contact

## Structure

- `assets/css/styles.css` — shared responsive styling
- `assets/js/main.js` — shared navigation, transitions, and interactions
- `assets/img/` — brand imagery
- `assets/icons/ui.svg` — shared interface icon sprite

Business information, phone/social/review/map destinations, logo asset, and existing site behavior are preserved.
